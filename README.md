# doctoral-proposal-writing

## 把长江学者亲自讲授的《学术写作》课程，蒸馏成一套能把研究推进到论文的 Skill

从一句研究想法，到一个可论证、可验证、可投稿的研究成果。

`doctoral-proposal-writing` 把问题意识、选题判断、文献缺口、开题设计、模型/算法论文结构、结果分析、期刊匹配和审稿回应，编译成一个可直接调用的科研写作工作流。它不替你堆砌漂亮段落，而是持续追问：问题是什么，证据在哪里，方法如何回答问题，结果能支持什么结论。

## 它能做什么

- 从宽泛主题提炼核心科学问题
- 比较已有研究，形成有边界的候选文献缺口
- 用 `why–what–how` 生成详细开题骨架
- 建立目标—内容—方法—评价—成果矩阵
- 按 Introduction → Problem Formulation → Model → Methodology → Results → Conclusions 组织模型/算法论文
- 组织计算环境、评价指标、比较基线、结果解释和研究启示
- 检查论文与期刊范围、文章类型、格式要求和投稿材料的匹配度
- 把审稿意见拆成可执行的修改、补证和逐点回应
- 检查创新主张、研究逻辑、可行性和风险
- 在证据不足时明确标出待核验项，而不是用漂亮话填空

## 三种用法

```text
帮我写开题报告。我的研究主题是：……
```

```text
这是我的研究设想，先帮我提炼核心科学问题，再判断需要补哪些文献。
```

```text
这是我的开题报告草稿，按阻断问题、重要问题、一般问题审查逻辑、创新性、方法和可行性。
```

```text
这是我的模型和算法，帮我搭建一篇完整的英文论文结构，重点检查结果、基线比较和贡献是否对应。
```

```text
这是审稿意见和论文，帮我按问题类型生成逐点修改与回复表，并标出仍需补证据的地方。
```

## 安装

把整个 `doctoral-proposal-writing` 文件夹放进 Codex 的 `skills` 目录，保留 `references/` 和 `agents/` 目录。安装后重启 Codex 或刷新 Skill 列表。

在仓库目录中也可以直接执行：

```bash
mkdir -p ~/.codex/skills/doctoral-proposal-writing
cp -R ./doctoral-proposal-writing/. ~/.codex/skills/doctoral-proposal-writing/
```

安装完成后，用下面这句话验证：

```text
帮我把这个研究主题变成一份详细的开题报告骨架：……
```

正常输出应包含研究问题、证据状态、结构映射、方法与评价、结果边界、风险或投稿缺口，并明确待确认事项。

## 适用范围

适合博士、硕士开题报告、中文研究计划、模型/算法论文写作和投稿准备。它负责研究逻辑与写作结构，不替代目标院系或期刊的最新指南、学科方法审查、伦理审批、数据许可或正式文献新颖性审计。

## 来源

方法框架来自一门由长江学者亲自讲授的《学术写作》课程的学习整理与个人实现。课程原始材料、个人研究材料和蒸馏过程不包含在本仓库中；仓库只发布抽象后的执行框架。
