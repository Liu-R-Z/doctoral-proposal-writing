# doctoral-proposal-writing

## 把长江学者亲自讲授的《学术写作》课程，蒸馏成一个真正能推进开题的 Skill

从一句研究想法，到一条能讨论、能验证、能继续写下去的研究方案。

`doctoral-proposal-writing` 不是把目录换个顺序，而是把问题意识、选题判断、文献缺口和研究设计，变成一套可直接调用的科研工作流。给它一个主题或一份草稿，它会帮你找到问题、搭起结构、标出证据缺口，并发现方案里真正会卡住研究的地方。

## 它能做什么

- 从宽泛主题提炼核心科学问题
- 比较已有研究，形成有边界的候选文献缺口
- 用 `why–what–how` 生成详细开题骨架
- 建立目标—内容—方法—评价—成果矩阵
- 检查创新主张、研究逻辑、可行性和风险
- 在证据不足时明确标出待核验项，而不是用漂亮话填空

## 三种用法

```text
帮我写开题报告。我的研究主题是：……
```

```text
这是我的研究设想，先帮我提炼核心科学问题，再判断需要补哪些文献。
```

```text
这是我的开题报告草稿，按阻断问题、重要问题、一般问题审查逻辑、创新性、方法和可行性。
```

## 安装

把整个 `doctoral-proposal-writing` 文件夹放进 Codex 的 `skills` 目录，保留 `references/` 和 `agents/` 目录。安装后重启 Codex 或刷新 Skill 列表。

在仓库目录中也可以直接执行：

```bash
mkdir -p ~/.codex/skills/doctoral-proposal-writing
cp -R ./doctoral-proposal-writing/. ~/.codex/skills/doctoral-proposal-writing/
```

安装完成后，用下面这句话验证：

```text
帮我把这个研究主题变成一份详细的开题报告骨架：……
```

正常输出应包含核心问题、文献缺口状态、研究目标、研究内容、方法、评价、技术路线、风险和待确认事项。

## 适用范围

适合博士、硕士开题报告和中文研究计划。它负责研究问题与方案结构，不替代目标院系的最新模板、学科方法审查、伦理审批、数据许可或正式文献新颖性审计。

## 来源

方法框架来自一门由长江学者亲自讲授的《学术写作》课程的学习整理与个人实现。课程原始材料、个人研究材料和蒸馏过程不包含在本仓库中。
