# 术语表

| 术语 | 含义 |
|---|---|
| 问题意识 | 对研究对象持续追问，并让核心问题贯穿研究设计 |
| 科学问题 | 能通过研究解释、建模、检验或设计回答的问题 |
| 研究目标 | 为解决核心问题而计划形成的可检查成果 |
| 研究内容 | 围绕目标拆分出的相互关联的子问题或工作包 |
| 关键问题 | 最需要解释、建模、突破或验证的节点 |
| why-what-how | 为什么研究、研究什么、如何研究的论证骨架 |
| 文献缺口 | 已有研究覆盖不足且当前方案有条件处理的具体问题 |
| 可行性 | 问题、材料、方法、资源和时间是否支持计划完成 |
| 预期成果 | 尚未完成、但可以定义验收标准的研究产物 |
