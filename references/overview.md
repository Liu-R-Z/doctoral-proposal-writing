# 学术写作与论文推进

`doctoral-proposal-writing` 是一个面向研究生和科研工作者的学术写作工作流。它把宽泛主题、现实痛点或已有研究材料，推进为有问题意识、有证据边界、可继续执行的开题方案，并支持后续模型/算法论文组织、投稿匹配和审稿回应。

## 能力范围

- 从主题、现象或实际需求中提炼边界清晰的科学问题。
- 比较已有研究的问题、假设、方法、适用范围和不足，形成待核验的研究缺口。
- 用 why-what-how 组织研究目的、研究目标、研究内容、关键问题、方法和技术路线。
- 建立目标—内容—方法—评价—成果矩阵，检查方案是否可执行。
- 按问题、模型、方法、结果和贡献组织模型/算法论文。
- 组织计算环境、评价指标、比较基线、结果解释和研究启示。
- 检查论文与期刊范围、文章类型、格式要求和投稿材料的匹配度。
- 把审稿意见拆成修改、补证和逐点回应任务。

## 工作主线

现实痛点或文献观察 → 明确研究对象与边界 → 提炼科学问题 → 判断选题价值与文献缺口 → 设计目标、内容和方法 → 安排技术路线与阶段任务 → 说明评价、成果、风险和可行性 → 形成开题报告或论文工作副本。

## 研究成果结构

模型或算法论文通常需要让以下部分相互对应：Introduction、Problem Formulation and Assumption、Mathematical Model、Methodology、Example/Simulation、Results、Implications 和 Conclusions。结构不是固定格式模板；每一部分都应服务于核心问题，并由相应的推导、实验、比较或文献证据支撑。

开题报告、学位论文和学术论文承担不同任务。开题报告重在研究计划和可行性，学位论文重在系统完整，学术论文重在压缩背景并突出问题、方法、结果和贡献。

## 使用边界

- 不编造文献、数据、实验结果、创新点、导师意见、研究基础或录用结果。
- 不把课程示例、旧格式、学校习惯或模型示例直接当作当前项目事实。
- 不用结构完整替代新颖性检索、学科方法审查、伦理审批、数据许可或统计核验。
- 目标院系、学校和期刊的最新模板、范围、格式与政策必须通过当前官方来源核对。
- 材料不足时输出结构化待确认清单，不把候选方案伪装成定稿。
