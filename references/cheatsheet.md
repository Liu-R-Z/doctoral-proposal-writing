# 决策规则速查 — 博士生专业写作课程：课题选择、开题、论文写作与投稿

| 能力 | 一句话规则 |
|---|---|
| 科学问题提炼 | 先把主题或痛点收束成一个有对象、边界、条件和可验证结果的核心科学问题。 |
| 选题与文献缺口判断 | 用文献比较和研究条件检查学术性、创新性、系统性与可行边界，不把“研究较少”当作创新证据。 |
| 开题方案设计 | 用 why-what-how 把核心问题展开为目标、内容、关键问题、方法、路线、阶段、成果和风险。 |
| 开题逻辑、可行性与边界审查 | 用假设—论证—结论和目标—内容—方法—成果矩阵审查逻辑、可行性、现实边界与风险。 |
| 模型与算法论文结构及结果表达 | 把研究问题沿着引言、假设、模型、方法、实验结果和结论组织成可追溯的论文结构。 |
| 期刊匹配、投稿策略与审稿回应 | 用期刊范围、文章类型、格式、成熟度和评审关注点制定投稿与回应动作。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
