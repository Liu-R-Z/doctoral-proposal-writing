# 科学问题提炼

## 目标

把宽泛主题、现实痛点或产品想法，推进成有研究对象、边界、条件和可验证结果的核心科学问题。

## 工作步骤

1. 区分背景现象、业务需求、研究主题和科学问题。
2. 明确研究对象、作用条件、关键机制或决策关系。
3. 指出问题的范围：研究什么、不研究什么。
4. 将问题改写成能够由数据、模型、理论分析或实验回答的问题。
5. 检查题目、核心问题、研究目标和后续章节是否使用同一组关键概念。

## 输出格式

- 研究对象：
- 现实或理论现象：
- 核心矛盾：
- 核心科学问题：
- 研究边界：
- 可观察结果：
- 仍需确认：

## 质量检查

- 不能把平台、算法或产品名称直接当作科学问题。
- 不能把“研究较少”直接写成研究缺口。
- 不能为了显得具体而擅自补入数据、机制、场景或结论。
- 一个开题方案应有一个主问题，子问题服务于主问题。
