# 选题与文献缺口判断

## 目标

把“已有研究做了什么”和“本研究还要解决什么”分开，避免用引用数量或空泛的“研究不足”代替缺口分析。

## 比较维度

建立文献比较表，至少记录：

- 研究对象与研究问题
- 理论或机制假设
- 数据与样本范围
- 模型、方法或实验设计
- 评价指标
- 适用条件
- 已知局限
- 与当前主题的关系

## 工作步骤

1. 按研究问题而不是按作者名单组织文献。
2. 区分事实共识、方法差异、适用边界和真正未解决的问题。
3. 检查候选缺口是否能被当前数据、方法和研究范围覆盖。
4. 将缺口写成待验证的研究命题，不把它提前写成已证实创新。
5. 明确哪些判断需要全文文献审计。

## 输出格式

- 已有共识：
- 主要方法路线：
- 关键分歧：
- 已知局限：
- 候选研究缺口：
- 需要核验的相似工作：
- 当前创新主张强度：候选 / 部分支持 / 已核验

## 边界

摘要、标题和搜索片段只能用于筛选，不能单独支撑新颖性结论。没有文献材料时，只能输出候选缺口和检索任务，不能宣布“国内外首次”或“填补空白”。
